# 2026 가을특별새벽부흥회

더THE사랑교회 2026 가을특별새벽부흥회 안내 사이트입니다.

> **하나님의 사랑에서 끊을 수 없으리라** (롬 8:38-39)

- **일시:** 2026.10.12(월) – 10.17(토)
  - 월~금 새벽 5:00, 토 새벽 6:00
- **장소:** 더THE사랑교회 본당
- **사이트:** https://leemyeongje.github.io/2026thesarang/

## 화면 구성

- **출석 체크:** 첫 화면은 인쇄된 출석 체크표를 그대로 옮긴 판입니다. 오늘 날짜의 원은 색칠되어 표시됩니다.
- **날짜별 화면:** 날짜 원을 누르면 그날의 화면이 열립니다(`/day1` ~ `/day6`).
  - 말씀 카드: 누르거나 옆으로 밀면 뒷면의 본문 말씀이 보입니다.
  - 설교 영상과 AI 요약: 새벽예배 후에 올라옵니다.

## 설교 올리기

`sermon/dayN.md` 파일 하나만 추가하면 그날 화면에 영상과 요약이 나타납니다. 다른 파일은 고칠 필요가 없습니다.

```markdown
https://youtu.be/영상주소

# AI 요약
## 1. 첫 번째 소제목
- 라벨: 내용을 적습니다.
- 라벨 없이 적어도 됩니다.
## 2. 두 번째 소제목
- ...
```

- 첫 번째 YouTube 주소가 영상으로 들어갑니다.
- `#`은 라벨, `##`은 소제목, `-`는 항목이 됩니다.
- 항목 앞의 짧은 `라벨: `은 굵게 표시됩니다.

## 로컬에서 보기

```sh
python3 -m http.server 8000
```

http://localhost:8000 을 엽니다. 날짜별 화면은 `/day1.html`처럼 확장자를 붙여 엽니다.
`index.html`을 파일로 바로 열면 설교와 영상이 불러와지지 않습니다.

## 수정할 때

- 빌드 과정 없이 `index.html`, `style.css`, `app.js`만으로 이루어진 정적 사이트입니다. GitHub Pages로 배포됩니다.
- 날짜별 제목·본문은 `app.js` 맨 위의 `DAYS`에 있습니다.
- `index.html`이나 `DAYS`를 고친 뒤에는 날짜별 페이지를 다시 만듭니다. `day1.html` ~ `day6.html`은 직접 고치지 않습니다.

  ```sh
  python3 tools/build_day_pages.py
  ```

- 말씀 카드 이미지를 바꾸면 `assets/cards/`의 webp도 다시 만듭니다.

## 폴더

| 경로 | 내용 |
